# UV Alert

Daily UV forecast notifications using GitHub Actions, Open-Meteo, and Telegram.

## Configuration

Repository **Settings → Secrets and variables → Actions**:

### Variables

| Variable               |      Example | Description                                |
| ---------------------- | -----------: | ------------------------------------------ |
| `LATITUDE`           |  `43.6532` | WGS84 latitude                             |
| `LONGITUDE`          | `-79.3832` | WGS84 longitude                            |
|  `NOTIFICATION_HOUR` |        `7` | Local hour, 0–23                          |
| `UV_THRESHOLD`       |        `5` | Alert when daily max UV reaches this value |
| `FORECAST_DAYS`      |        `7` | 1–16                                      |

### Secrets

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

No timezone variable is needed. The setup workflow asks Open-Meteo for `timezone=auto`; Open-Meteo resolves the local timezone from the coordinates. citeturn0search2

## Setup

1. Configure the Variables and Secrets.
2. Open **Actions → Setup UV Alert Schedule → Run workflow**.
3. The workflow resolves the timezone and generates `.github/workflows/uv-alert.yml`.
4. It commits that generated workflow.
5. Use **Actions → UV Alert → Run workflow** for an immediate test.

If latitude, longitude, or notification hour changes, run Setup again.

The generated schedule looks like:

```yaml
on:
  schedule:
    - cron: "0 7 * * *"
      timezone: "America/Toronto"
```

GitHub supports IANA timezone-aware schedules and DST handling. Scheduled workflows run from the default branch and can be delayed, so this is not hard real-time scheduling. citeturn0search0turn0search1

## UV logic

The application requests Open-Meteo's daily `uv_index_max`. Open-Meteo supports up to 16 forecast days. citeturn0search2

If no day reaches `UV_THRESHOLD`, no Telegram message is sent. If multiple days reach the threshold, they are included in one message.

`UV_THRESHOLD=5` means UV Index ≥ 5. It is a UV Index threshold, not literally 50% solar intensity.
